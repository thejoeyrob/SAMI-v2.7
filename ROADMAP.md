# SAMI — Proposed, not applied after v2.7.13

Ordered by field value and risk reduction. These items were deliberately not improvised into this static release.

1. **Authoritative utilities integration.** Contract licensed electricity, gas, water and sewer data providers or user organisations; normalise provenance, issue date, confidence and permitted export use. Public mapping must never imply that an unshown asset is absent.
2. **Production service gateway.** Proxy geocoding, routing, OHL/Overpass and optional AI through an identified, monitored, rate-limited service with caching, provider-specific policies and no client secrets.
3. **Physical-device release qualification.** Complete the supplied checklist on representative iPhone, iPad, Android tablet/phone, Windows touch device and macOS; include OS-kill recovery and populated-project upgrade.
4. **SAMI AI backend.** Implement the contract in `SAMI_AI_BACKEND_SPEC.md` with server-side credentials, official-source grounding, audit logs and the strict structured-action allowlist already enforced by the client.
5. **Licensed offline map areas.** Use a contracted/self-hosted provider that explicitly permits bounded offline downloads; add area/zoom selection, byte estimate, quota reserve, expiry and deletion. Do not bulk-prefetch current public tile endpoints.
6. **Cold-start module separation.** Untangle documents, catalogue, studio and import dependencies so genuinely optional code loads after the first useful screen. Retest every export/import and serve Brotli/gzip.
7. **Independent accessibility certification.** Audit all modes and imported content against WCAG 2.2 with VoiceOver/TalkBack, keyboard-only operation, 200% zoom, sunlight and gloves.
8. **Deployment hardening and monitoring.** Add server headers unavailable to a meta CSP, uptime/error monitoring, service health, privacy/retention documentation and a tested rollback channel.
9. **Large-project storage architecture.** Add schema-tested IndexedDB write-ahead recovery, external attachment handling and cross-tab edit ownership without changing existing data silently.
10. **Media optimisation.** Re-encode only after iOS/Android quality and compatibility tests; regenerate matching recordings whenever wording changes.
11. **Optional share/file handlers.** Add only after device testing confirms predictable KML/KMZ/GeoJSON/Visio handoff and install behaviour.
